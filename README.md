# 🎮 Rock Paper Scissor Game

Welcome to the **Rock Paper Scissor Game** — a modern, interactive version of the timeless classic.  
Built with **HTML, CSS, and JavaScript**, this project lets you challenge the computer, track your wins, losses, and ties, and enjoy a sleek, responsive interface.

---

## ✨ Features
- 🖱️ **User vs Computer Gameplay** — click your move and see the computer’s choice instantly.
- 📊 **Dynamic Scoreboard** — track User, Computer, and Tie scores in real time.
- 🎨 **Clean UI & Animations** — hover effects, styled messages, and responsive design.
- ⚡ **Lightweight & Fast** — no frameworks, just pure HTML, CSS, and JS.
